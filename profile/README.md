## What we build

Small, focused libraries you drop into an app you already have. There is no framework to adopt and
no `axonpack` meta-package to install. Each library is published, versioned and documented on its
own, and installing one never brings in another. All of it is MIT.

## Getting involved

Bug reports, questions and pull requests are all welcome. Open them on
[`axonpack/axonpack`](https://github.com/axonpack/axonpack/issues), including for anything wrong in
the docs. Read [CONTRIBUTING.md](https://github.com/axonpack/axonpack/blob/main/CONTRIBUTING.md)
first if you are sending a PR: it covers the branch names, the commit format and the checks that
have to pass.

Good first contributions: a reproduction for a bug you hit, a missing case in a package's tests, or
a docs page that told you the wrong thing.
